# 🗣️ Indic-English Speech Translator

A two-way speech translator for South Indian languages (Tamil, Telugu, Kannada, Malayalam) and English. 

## 📱 How to Run This on Your Xiaomi Pad 6 (No Laptop Needed)

Since you are using a tablet, we will host this app for **free** on Streamlit Community Cloud so it runs directly in your Chrome browser.

### Step 1: Create a GitHub Repository
1. Open the GitHub app or go to `github.com` in your browser.
2. Create a **New Repository** (e.g., name it `indic-translator`).
3. Make it **Public** (required for free Streamlit hosting).

### Step 2: Upload the Files
1. Inside your new repo, tap **Add file** -> **Create new file**.
2. Name it `app.py`, paste the code for `app.py`, and commit it.
3. Repeat for `requirements.txt` and `README.md`.

### Step 3: Deploy to Streamlit Cloud
1. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with your GitHub account.
2. Click **Create app**.
3. Select your `indic-translator` repository.
4. Set the Main file path to `app.py`.
5. Click **Deploy!**

### Step 4: Use the App
1. Once deployed, open the URL in your Xiaomi Pad's browser.
2. **Allow Microphone Permissions** when the browser prompts you.
3. Tap the mic button, speak in your chosen language, and the app will translate and speak back!

*Note: The first time you open the app, it will take 2-3 minutes to download the AI models. Subsequent loads will be much faster.*
